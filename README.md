# MultiVPN

Android-клиент с единым интерфейсом сразу для нескольких VPN-протоколов.
Каждый протокол — отдельный плагин поверх официального или проверенного
открытого движка, без собственных реализаций протоколов с нуля.

## Поддерживаемые протоколы

| Протокол | Движок | Статус |
|---|---|---|
| AmneziaWG | com.zaneschepke:amneziawg-android | Работает |
| WireGuard | тот же движок, что и AmneziaWG | Работает |
| IKEv2/IPsec | strongSwan | Работает |
| L2TP/IPsec | TunnelForge | Работает |
| OpenVPN | openvpn3 (ядро от OpenVPN Inc.) | Работает |
| VLESS | Xray-core (через XTLS/libXray) | В процессе |
| SSTP | kittoku/Open-SSTP-Client | В процессе |

## Возможности

- Несколько сохранённых профилей, переключение между ними в один тап.
- Сплит-туннель (выбор конкретных приложений) — там, где это поддерживает
  протокол.
- Импорт профилей: вручную, из файла (.conf/.ovpn/.json и др.), по QR-коду
  или по ссылке (vless://).
- Экспорт профилей — одиночный профиль в "родном" формате протокола, либо
  несколько сразу в одном .zip-архиве.
- Подробное логирование подключения (по желанию, включается в настройках) с
  экспортом в .zip для диагностики.
- Индивидуальные значки под каждый протокол, единый тёмный дизайн.

## Архитектура

Плагинная: общий интерфейс `VpnPlugin` (`connect`/`disconnect`/
`importProfile`/`exportProfile`/`validate`), плагины регистрируются через
Hilt (`di/PluginModule.kt`). У каждого протокола — свой Gradle-модуль или
пакет внутри `app`, свой native/JNI-мост там, где движок нативный.

Подробности по используемым сторонним движкам и их лицензиям — см.
[`LICENSES-THIRD-PARTY.md`](LICENSES-THIRD-PARTY.md).

## Сборка

Проект вендорит исходники нескольких сторонних движков (L2TP, OpenVPN, SSTP)
заново на каждом прогоне CI — они не хранятся в этом репозитории напрямую
(см. `.github/workflows/build.yml`). Для локальной сборки нужно вручную
выполнить соответствующие шаги вендоринга/скачивания перед `./gradlew
assembleDebug` — см. комментарии в начале `build.yml` и в
`build.gradle.kts` каждого модуля.
